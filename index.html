BG NOW

個人用のダッシュボード / A personal dashboard

このアプリについて

BG NOW は、作成者本人だけが自宅で使う個人用のダッシュボードです。 自宅の PC で動き、同じ Wi‑Fi の自分の端末に、今日の予定・タスクと、AI ツールの使用量を表示します。

Google カレンダーと Google ToDo リストの内容を読み取り専用で取得し、 「次の予定」「今日の予定」「今日のタスク」として表示します。

BG NOW is a personal dashboard used only by its author at home. It reads (read-only) Google Calendar and Google Tasks to show today's schedule and tasks on the author's own devices.

プライバシーポリシー

最終更新日: 2026年10月27日

取得する情報

  • Google カレンダーの予定（題名・日時・場所・カレンダーの名前と色）
  • Google ToDo リストの未完了のタスク（題名・期限）

使用する権限は次の 2 つだけで、いずれも読み取り専用です。予定やタスクを作成・変更・削除することはありません。

  • https://www.googleapis.com/auth/calendar.readonly
  • https://www.googleapis.com/auth/tasks.readonly

情報の使い方

  • 取得した情報は、作成者本人の端末に今日の予定とタスクを表示するためだけに使います。
  • 広告、分析、機械学習の学習などには使いません。

保存と共有

  • 情報とログインのトークンは、作成者の自宅の PC の中だけに保存します。
  • 第三者への提供・販売・公開はしません。外部のサーバーやクラウドにも送信しません。

アクセスの取り消し

Google アカウントの サードパーティ アクセス から、 いつでも BG NOW のアクセス権を削除できます。削除すると、BG NOW は情報を取得できなくなります。

Google API サービスのユーザーデータに関するポリシー

BG NOW による Google API から受け取った情報の使用は、 Google API Services User Data Policy （Limited Use の要件を含む）に従います。

BG NOW only uses read-only access to Google Calendar and Google Tasks to display the author's own schedule and tasks. Data stays on the author's home PC and is never shared, sold, or sent to third parties. BG NOW's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
